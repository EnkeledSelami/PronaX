The compressed albania-amenities.json.gz file is a category-filtered,
coordinate-indexed derivative of POI, transport, traffic, places-of-worship,
and land-use layers in the Albania regional extract. It includes education,
health, green spaces, transport, groceries, retail, restaurants/cafes, fitness,
entertainment, parking, civic/safety, tourism, vehicle services, personal
services, finance, and utilities. It is bundled with the app so nearby counts
do not need a live Overpass query service.
OpenStreetMap mapping coverage is incomplete and varies by location.

Tirana housing-price map payload: tirana-market-prices.json
Neighbourhood sale-listing aggregates: Prona, https://pronatirana.com/en/cmimet
Neighbourhood coordinates: OpenStreetMap Nominatim label points, captured 2026-10-28. Points are not neighbourhood boundaries.
Municipal-unit boundaries: OpenStreetMap contributors, Albania Geofabrik extract downloaded 2026-10-27, ODbL 1.0.
Municipal-unit published average figures: Keydata Q2 2026, as published by Hyrja, https://hyrja.al/en/blog/apartment-prices-tirana-by-area-2026
The Prona neighbourhood listing medians and Keydata municipal-unit averages are different metrics from different sources; the app presents them in separate overlays and does not substitute one for the other.

The index also includes selected road network geometry and a road-class score used only for the illustrative hourly context view. Traffic, noise and road-impact colors are modeled relative estimates; the dataset contains no measured hourly traffic, decibel or air-quality observations.
